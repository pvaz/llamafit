# LlamaFit 0.1.2 release preparation

Version 0.1.2 is prepared locally and is not published. The latest published package and
standalone binaries remain 0.1.1. Their download examples remain unchanged until a new
release exists. The starting commit is `b03af4b` on `main`; the corrections already
integrated by PR #9 are included in the preparation.

## Scope

The release includes the terminal shutdown race correction, shell-aware copied commands,
explicitly bound local Host handling, Hugging Face credential origin restriction and
literal POSIX installation paths recorded in the [changelog](../../CHANGELOG.md).

It also rejects unusable generation-speed targets before planning. Previously,
`plan qwen3.8-flash-next --target-tps 0` reached `TargetCheck` and raised a raw Pydantic
validation error. CLI and API inputs now require a finite number greater than zero;
positive fractional targets remain valid. API validation failures retain their HTTP 422
`detail` shape even when rejected raw JSON contains NaN, infinity or an overflowing number.
Validation responses expose each error's type, field location and message, without echoing
the rejected input or internal context. Non-finite numbers never become planning inputs.

## Environment notes

The first offline editable-install attempt failed because the available build environment
lacked `editables`. No package was downloaded. A normal wheel does not need that editable
backend dependency; local wheel installation can provide 0.1.2 metadata while the isolated
source-first environment continues to test this checkout.

Installing the local wheel supplied version 0.1.2 metadata. Import verification confirmed
that tests still load this checkout's `src/llamafit`, through the isolated environment's
source-first path. The coordinating dependency audit uses the effective environment and
its local `urllib3` 2.8.0; the original development environment is unchanged.
The separate smoke environment uses `pip` 26.2.1 in place of the 24.3.1 installed by
`ensurepip`; its audited dependency set contains only the base installation and tooling,
not the development or web extras.

A broad `ruff check .` initially traversed local temporary artifacts, reported access
errors and then crashed inside Ruff. The successful retry covered every source, test,
script and packaging directory while excluding those generated artifacts; the failure
does not establish a source-code defect or count as a successful check.
